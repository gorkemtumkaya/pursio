# Product: Pursio

Pursio turns any hobby into a gamified learning path. The user types a hobby and AI builds a skill tree. Each skill has a short description, 3 small quests and fresh web content. Completing skills gives XP, levels and streaks and unlocks the next skills. Wick, a lantern spirit mascot, dresses for the hobby.

Promise: "ChatGPT tells you the path; Pursio walks it with you."

Audience: beginner and intermediate hobbyists and self-learners. Not experts, not casual fans.

## MVP scope (Kiroween 2026, Nov 8 – Dec 4)
- AI skill tree generation
- Path view with sections, side quests and milestones
- Node detail with quests (bottom sheet on mobile, side panel on desktop)
- Progress: XP, levels, streak
- Fresh content per node (RSS + YouTube, AI-tagged and summarized)
- Wick with hobby outfits
- Landing page with live "type a hobby, get a tree" demo + waitlist

## Out of scope (later)
Social feed, matching with other users, leaderboards, payments, native app, photo/video progress logs.

## Rule
If it doesn't improve the first 30 seconds of the demo, it waits.
